# Supernatural — Guia da série

Landing page sobre Supernatural, desenvolvida para a **Atividade 1 — Landing Page HTML e CSS** do curso de Front-end PROA Transforme-se com a Serasa.

## Sobre o projeto

A página apresenta a história da série, os personagens Sam Winchester, Dean Winchester e Castiel, o Chevrolet Impala 1967 e algumas curiosidades. O visual utiliza cores escuras e imagens inspiradas no universo da série.

## Tecnologias utilizadas

- **HTML5:** estrutura da página com cabeçalho, seções, cards de personagens e rodapé.
- **CSS3:** cores, fontes, espaçamentos, imagens e layout responsivo.

## Recursos da página

- Apresentação da série e de seus personagens.
- Seção dedicada ao Impala.
- Botão **Pegar a Estrada** que leva à seção de personagens.
- Imagens com textos alternativos.
- Link para pular diretamente ao conteúdo.
- Adaptação do layout para telas menores.

## Como visualizar

1. Baixe o repositório em **Code → Download ZIP** e extraia os arquivos.
2. Abra o arquivo `index.html` no navegador.

Mantenha o arquivo `style.css` e a pasta `imagens` junto do HTML. Não é necessário instalar bibliotecas ou executar comandos.
